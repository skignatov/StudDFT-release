# StudDFT

This is the new release (v.1.08.3) of scientific-educational quantum chemistry program StudDFT.
The older version 0.82.1 is placed in the root directory for the compatibility with the original article: 
S.K. Ignatov "StudDFT: A compact quantum chemistry program for educational and research purposes", Zhurn.Fiz.Khimii (rus.), (accepted in June, 2026)

## New Features
- RHF/UHF, RKS/UKS, MP2/UMP2/PUMP2 calculations
- LDA, GGA, hybrid-GGA, meta-GGA, range-separated-hybrid-GGA (SVWN, BLYP, BP86, BPW91, PBE, PBE0, B3LYP, r2SCAN, WB97X, WB97XD)
- Cartesian and spherical basis sets with optional ECPs
- SP energy, geometry optimization, frequency calculations, PES scanning, TS search, IRC, BSSE
- Analytical energy gradients and Hessians
- RI-DFT (J and JK) 
- TD-DFT 
- CDFT
- Windows and Linux releases
